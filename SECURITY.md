# Security Policy

## Reporting a vulnerability

Please do not publish exploit details or sensitive files in a public issue. Contact the repository maintainer privately through the contact option available on the GitHub repository. Include the affected file/version, impact, reproduction steps, and a suggested fix if known.

## Scope

Evertech Mod Studio is designed to run locally in the user's browser. Do not import untrusted model files into a browser session you use for sensitive work. This project makes no claim that every model parser or browser API is free of vulnerabilities.
