# Community Code of Conduct

We want participation in Evertech Mod Studio to be welcoming and constructive.

Examples of expected behavior:
- Be respectful and patient with people of different experience levels.
- Give technical feedback about the work, not personal attacks.
- Accept good-faith corrections and differing viewpoints.
- Respect privacy and only share assets or data you have permission to distribute.

Unacceptable behavior includes harassment, threats, discrimination, doxxing, and persistent disruptive conduct. Project maintainers may edit or remove harmful contributions and may restrict participation when necessary.

Report conduct concerns privately to the repository maintainers using the contact method listed on the GitHub repository. Do not post sensitive details in a public issue.
